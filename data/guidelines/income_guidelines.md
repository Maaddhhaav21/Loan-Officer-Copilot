# Synthetic Income Underwriting Guidelines

> This document contains synthetic rules created for the Loan Officer Copilot demo.
> These rules are not official mortgage underwriting guidelines.

## INC-001 — Income Consistency

The income reported on the loan application should be reasonably consistent with supporting income documentation.

Supporting documents may include:

- W-2 forms
- Pay stubs
- Tax returns
- Other documented income records

If the application income differs materially from verified supporting income, the discrepancy should be reviewed.

### Review Actions

- Compare application income with verified income.
- Review recent pay stubs.
- Review W-2 income.
- Review tax return income when applicable.
- Determine whether the difference has a documented explanation.

## INC-002 — Employment and Income Verification

Employment information should be consistent across the loan application and supporting income documents.

The following information may be compared:

- Employer name
- Job title
- Employment start date
- Employee name
- Reported income

If material inconsistencies are identified, additional documentation or clarification may be required.

## INC-003 — Income Documentation

Income should be supported by appropriate documentation before the loan file is considered complete.

Common supporting documents include:

- Recent pay stubs
- W-2 forms
- Tax returns when applicable
- Employment documentation

Missing income documentation should be identified as an open loan condition.
