# Synthetic Asset Underwriting Guidelines

> This document contains synthetic rules created for the Loan Officer Copilot demo.
> These rules are not official mortgage underwriting guidelines.

## AST-001 — Asset Consistency

Assets reported on the loan application should be reasonably consistent with supporting account documentation.

Assets may include:

- Checking accounts
- Savings accounts
- Other verified financial accounts

The declared asset amount should be compared with the verified asset amount.

If a material discrepancy exists, the difference should be reviewed.

### Review Actions

- Compare declared assets with bank statement balances.
- Identify differences between reported and verified balances.
- Review supporting bank statements.
- Request clarification when the discrepancy cannot be explained.

## AST-002 — Asset Documentation

Financial assets should be supported by appropriate documentation.

Supporting documentation may include:

- Bank statements
- Account summaries
- Other financial account documentation

Missing asset documentation should be identified as an open condition.

## AST-003 — Unexplained Deposits

Large deposits that are not clearly explained by the available documentation should be identified for review.

### Review Actions

- Identify the deposit amount.
- Review the transaction description.
- Determine whether the source of the funds is documented.
- Request supporting documentation when the source cannot be established.

The Loan Officer Copilot should not independently determine the source of an unexplained deposit.
