# Synthetic Employment Underwriting Guidelines

> This document contains synthetic rules created for the Loan Officer Copilot demo.
> These rules are not official mortgage underwriting guidelines.

## EMP-001 — Employment Consistency

Employment information should be consistent across the loan application and supporting documentation.

The following information should be compared:

- Current employer
- Job title
- Employment start date
- Employee name

If different employers are reported across documents, the discrepancy should be reviewed.

### Review Actions

- Compare the employer listed on the application with pay stubs.
- Compare the employer listed on the application with W-2 documentation.
- Review employment documentation when inconsistencies are identified.

## EMP-002 — Employment Gap

A documented gap between previous employment and current employment should be identified and reviewed.

An employment gap exists when:

- Previous employment has an end date, and
- Current employment begins after the previous employment end date.

### Review Actions

When an employment gap is identified:

1. Confirm the previous employment end date.
2. Confirm the current employment start date.
3. Determine the approximate length of the gap.
4. Review documentation covering the employment history.
5. Request clarification or supporting documentation when necessary.

## EMP-003 — Employment History

Employment history should provide sufficient information to understand the borrower's recent employment background.

Relevant information may include:

- Previous employer
- Previous employment end date
- Current employer
- Current employment start date
- Job title

Missing or inconsistent employment information should be flagged for review.
